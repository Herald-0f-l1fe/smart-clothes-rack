# Топик проекта

## Тема

**«Умная вешалка» (AutoRack)** — прототип напольной системы хранения одежды,
которая автоматически раздвигает каретки с крючками при добавлении новой вещи и
компактно сдвигает их при снятии, оптимизируя пространство рейки и давая
пользователю визуальную обратную связь.

Проектное предложение ВЦП ПЦП, осень 2026. Команда: Ковальков Борис (Б01-502),
Сидорова Елена (Б01-511). Ментор: Азамат Георгиевич Тавитов.

## Описание репозитория

```
AutoRack: прототип умной вешалки на ESP32. Сама раскладывает крючки по рейке,
определяет занятость мест FSR-датчиками и подсвечивает свободный крючок.
Механика — фанера, лазерная резка и 3D-печать.
```

Короткое описание:

```
Прототип напольной вешалки, которая сама распределяет одежду по рейке и
подсказывает свободное место светом.
```
