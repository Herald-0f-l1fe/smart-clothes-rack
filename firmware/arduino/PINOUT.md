# Распиновка Arduino Uno (AutoRack)

Общая распиновка для всех скетчей в `arduino/`. Держим её одинаковой,
чтобы переключаться между тестами и рабочей программой без перекоммутации.

| Пино | Назначение | Примечание |
|---|---|---|
| A1 | STEP (DRV8825) | шаг мотора |
| A2 | DIR  (DRV8825) | направление |
| A3 | EN   (DRV8825) | `LOW` = драйвер включён |
| D2 | концевик **TIGHT** | `INPUT_PULLUP`, второй вывод на GND, `LOW` = нажат |
| D4 | концевик **SLACK** | `INPUT_PULLUP`, второй вывод на GND, `LOW` = нажат |
| D8 | зуммер (пассивный) | `tone()` / `noTone()` |
| D13 | статусный LED | встроенный на плате |
| A0 | PIR HC-SR501 OUT | `VCC` 5В, `GND` GND |
| D5/D6/D7/D10 | ULN2003 IN1..4 | только в тестах 28BYJ-48 |
| A4 | home-концевик NEMA | только в `nema_test` |

## Концевики (TIGHT / SLACK)

Микрик стоит в крайнем положении верёвки/барабана. Когда верёвка в этом
положении — микрик нажат (`LOW`); при уходе из положения — отпущен (`HIGH`).

- **TIGHT (D2)** — пружина полностью натянута, крючки разъехались.
- **SLACK (D4)** — пружина полностью ослаблена, крючки съехались.

Остановка мотора = дождаться **нажатия** (`LOW`) нужного концевика.
Шаги для остановки не считаются — только концевики (надёжно при проскальзывании).

## Питание

- Uno — от USB (5В). **12В на Uno не подавать.**
- NEMA 17 / DRV8825 — от блока 12В, конденсатор 100..220 мкФ по VMOT.
- **GND блока 12В и GND Uno обязательно соединить** (общая земля).
- DRV8825: `RST` и `SLP` соединить перемычкой. Ток: `I = Vref * 2` (Vref 0.3..0.4 В для теста).
