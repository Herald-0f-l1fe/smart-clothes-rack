# Прошивка AutoRack

ESP32, PlatformIO + Arduino framework. Подробности архитектуры — в разделе
«Программная часть» [корневого README](../README.md).

## Сборка и прошивка

```bash
cd firmware/smart_clothes_rack
pio run            # собрать
pio run -t upload  # залить в плату
pio device monitor # лог, 115200
```

## Состояния конечного автомата

| Состояние | Что происходит |
|---|---|
| `SLEEP` | пружина ослаблена, свет выключен, ждём PIR |
| `WAKE` | человек подошёл: подсветка + опрос массива FSR |
| `DISTRIBUTE` | мотор растягивает пружину, крючки раскладываются равномерно |
| `HINT` | 5 с без действий: верхняя каретка освобождает свободный крючок |
| `RESTORE` | вещь снята (падение веса): крючки возвращаются в равномерное положение |
| `COOLDOWN` | 5 минут без движения: гасим свет, ослабляем пружину |
